# صياد الوظائف الدولية — النسخة الأولى

هذا مشروع أولي قابل للتشغيل عبر GitHub Actions وإرسال تنبيهات Telegram.

## ما الذي يفعله الآن؟
- يبحث بكلمات مفتاحية للمخازن والإنتاج والتعبئة والمناولة والأعمال العامة.
- يستخدم Jooble API للدول المحددة، ويضيف Adzuna للدول التي يدعمها إعداد المشروع فقط.
- يخزن بصمة كل إعلان في SQLite ويمنع إرسال الإعلان نفسه مرة أخرى.
- يرسل تقريرًا عربيًا يوميًا.
- لا يعتبر وجود عبارة sponsorship ضمانًا للتأشيرة؛ بل يطلب تأكيدًا من صاحب العمل.

## حدود مهمة
- تغطية Jooble تختلف حسب الدولة والكلمات المفتاحية، ولا يعني عدم ظهور نتائج عدم وجود وظائف.
- إعداد Adzuna هنا يقتصر على رموز الدول المدرجة في `job_hunter.py`؛ لا توجد تغطية Adzuna مفعلة لرومانيا أو ألبانيا أو صربيا أو بلغاريا أو مالطا.
- لا يوجد في هذه النسخة تحقق قانوني آلي من أهلية المصريين. التصنيف مجرد فرز أولي، ويجب التأكد من صاحب العمل والجهة الرسمية.
- قد تتأخر GitHub Actions عن موعد cron، كما أن 07:00 UTC يساوي 09:00 في مصر خلال التوقيت الشتوي فقط. عدّل الموعد عند تغيير التوقيت الصيفي.
- لا يوجد تقديم تلقائي ولا إرسال مستندات شخصية.

## الإعداد
1. أنشئ بوت Telegram من `@BotFather` وخذ `TELEGRAM_BOT_TOKEN`.
2. أرسل رسالة للبوت ثم احصل على `TELEGRAM_CHAT_ID` (يمكن استخدام `getUpdates` من Telegram Bot API).
3. اطلب مفتاح Jooble API من بوابة المطورين الخاصة بهم. يمكن إضافة Adzuna لاحقًا عبر بياناتها.
4. أنشئ مستودع GitHub **Private** وارفع ملفات المشروع.
5. من Settings → Secrets and variables → Actions أضف:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
   - `JOOBLE_API_KEY`
   - اختياريًا: `ADZUNA_APP_ID` و`ADZUNA_APP_KEY`
6. من Actions شغّل `Daily International Job Alerts` يدويًا للاختبار.

## توسيع مصادر الدول
أضف مزودًا جديدًا فقط إذا كان لديه API أو RSS مسموح وموثق. لا تستخدم scraping يخالف شروط المواقع. احتفظ باسم المصدر والرابط الأصلي وتاريخ الإعلان.

## ملاحظة عن قاعدة البيانات
الـworkflow يحفظ `jobs.sqlite3` داخل المستودع عبر commit حتى تبقى ذاكرة منع التكرار بين التشغيلات. لهذا يجب أن يكون المستودع خاصًا، وألا تضع أي أسرار أو بيانات شخصية داخل قاعدة البيانات.
